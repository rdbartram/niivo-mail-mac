# niivo mail — feature backlog (mail + calendar first), 2026-11-19

Goal: an Outlook replacement on the Mac that the owner can use every day. That means close to full Outlook parity,
plus the best ideas from Superhuman, Spark, HEY, Mimestream, Apple Mail, Thunderbird and Fastmail.

**Status legend**
- **Done**: built and self-tested on fixtures. Unless Notes say otherwise, it has **not** been run against the real
  tenant: the mail UI has never been clicked through, and real-tenant mail is waiting on consent.
- **Partial**: some of it exists in core or UI, with a gap named in Notes.
- **Missing**: no code found (grep of `Sources/`, 2026-11-19).

**Priority legend**
- **P0**: needed to daily-drive.
- **P1**: first release after daily-driving.
- **P2**: later, or on request.

**Source tags**
- **Outlook** = new Outlook for Mac / Outlook on the web.
- **Owner** = Ryan's explicit ask.
- **User request** = something forums and reviewers keep asking for.
- Competitor behaviour not backed by a page in Sources is marked "(product knowledge)", as in MAIL-RESEARCH §2.

## P0 to daily-drive

**Blockers before anything else**
1. Mail consent on the app registration and the first real sign-in.
2. A real-mailbox read probe, then a go-ahead to send.
3. Click through the mail UI by hand. It has never been clicked through.
4. ~~Fix draft autosave, which creates a new server draft on every save.~~ Done 2026-11-20 (`DraftSession`, PATCH in place, stub-tested request sequence).
5. ~~Undo after a Graph move needs an id remap.~~ Done 2026-11-20 (`MailSync.currentId` / `undo`).
6. Handle the CAE claims challenge (CP1), so revocation doesn't surface as a sync error.

**Owner's P0 asks**
7. Rich-text composer with realistic Markdown: type Markdown and get formatted HTML (bold, italics, lists, links,
   code, quotes, headings, tables). Paste rich text keeps its formatting.
8. Attachments: open, Quick Look, save, attach (drag and drop and file picker), and the upload session for files of
   3 MB or more.
9. Inline media: paste or drop images into the body; render `cid:` images in the reader.
10. Signatures: several of them, a default per identity, separate new and reply/forward defaults.
11. AI context suggestions: who/what/related threads beside the reader and composer. The core exists (CommGraph,
    `people_history`, `project_context`); it needs surfacing in the app.
12. Add additional mailboxes by address: shared, delegated, other users', saved and restored on launch.
13. Microsoft 365 Groups: list the groups you belong to, read and reply to their conversations, see their calendars.
14. Folder CRUD: create, rename, move, delete, and nested folders at any depth.
15. Label picker with the Purview hierarchy: parent and sub-labels, in priority order, with justification on downgrade.
16. MIP decryption run live on real protected mail (built offline, off by default).
17. Desktop notifications for new mail: per-folder and VIP, no subject for labelled mail.
18. Open a message from search: single click or Return on any search hit opens it in the reader.

**Daily basics also P0**
19. Favourites, junk / not junk, print, and a meeting invite RSVP inline.
20. Drag mail to a folder, reliable conversation view, and a unified Inbox across your mailboxes.
